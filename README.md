# Applin

A bill splitting app for friends having a meal together. Everyone pays their own portion, calculated properly, GST and service charge included.

**[Try the live prototype](https://kairatanyx.github.io/applin/)**

## what this is

This is a clickable prototype, not a finished product. Groups, friends, and payment amounts are hardcoded for now, but the core flow works end to end: creating a group, adding your order, seeing the split calculated live, and tracking who's paid.

Full product thinking, scope, and the maths behind the split are in [applin-prd.md](applin-prd.md).

## how to view it

The easiest way is the live link above. If you want to run it locally instead, download `index.html` and open it in any browser, no installation or setup needed.

## built with

Plain HTML, CSS and JavaScript, no frameworks or build tools.

## status

Reminders, receipt reading, and real payments are all future work, laid out in the PRD.
